Created in /home/jay/Documents/Scripts/AI/Opencode/Projects/WEB-APPS/p2p-chat/:
- index.html — anonymous P2P chat app (WebRTC via Trystero/Nostr signaling)
- Create session: generates 6-digit PIN, share link (#room=PIN), and QR code; waits for peer
- Join session: via PIN entry or shared link/QR
- Chat: real-time P2P messages, copy-to-clipboard for received text
- Files: P2P chunked file transfer with download attachments for received files
- ICE: Google STUN + public TURN relays configured to broker NAT traversal
- README.md — features, usage, and notes
Run: open index.html in a modern browser (or python3 -m http.server 8000 in the folder). Share the PIN/link/QR with a peer; both must keep the tab open (internet required for signaling/ICE/CDN).
